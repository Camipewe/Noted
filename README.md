# Noted

Stick notes onto any website. Come back later and they're right where you left them.

## Install (takes about a minute)

1. Unzip `sticky-notes.zip` somewhere you won't delete it (like Documents).
2. In Chrome, go to `chrome://extensions`.
3. Turn on **Developer mode** (top-right toggle).
4. Click **Load unpacked** and pick the unzipped `sticky-notes` folder.
5. Click the puzzle-piece icon in the toolbar and pin **Noted**.

Already-open tabs need a refresh before notes work on them.

## Adding a note

- **Right-click** anywhere on a page → **Add sticky note here** (the note appears where you clicked; any highlighted text gets copied into it)
- **Keyboard:** `Alt+Shift+N` (Option+Shift+N on Mac)
- **Toolbar:** click the Noted icon → **Add sticky note**

If the shortcut says "Not set," another extension already uses it. Pick a new one at `chrome://extensions/shortcuts`.

## Using notes

- **Move:** drag the tape or the top of the note. Notes scroll with the page.
- **Resize:** drag the bottom-right corner.
- **This page / Whole site:** click the label in the top-left corner to choose whether the note shows only on this exact page or on every page of the site.
- **Color:** click the colored dot and pick one of 8 pastels, or the rainbow swatch for any custom color. New notes start in the last color you picked.
- **Minimize:** click the dash.
- **Delete:** click the ✕.

Everything saves automatically.

## The popup

Click the Noted icon in the toolbar:

- **Add sticky note** adds a note to the page you're on. The keyboard shortcut is shown on the button.
- **This page** lists the notes on the site you're looking at.
- **All notes** lists every note you've made, grouped by date (Today, Yesterday, This week, then by month).

Click any note in either list to jump to it. Hover over a note and click ✕ to delete it.

## Good to know

- Notes are saved on this computer only, in Chrome's extension storage. They don't sync between computers.
- Removing the extension deletes your notes.
- Chrome doesn't let extensions run on its own pages (`chrome://…`, the Chrome Web Store, the New Tab page).
